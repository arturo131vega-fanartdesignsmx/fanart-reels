# fanart-reels

Temporary hosting for FanartDesignsMX Instagram/Facebook Reels.

- `template/` — the approved Reel template (card tilt animation, animated "Handmade Proxy Cards" title,
  "ETSY Link in Bio" button, synced subtitles, English voice-over, visible "Fanart Designs MX" watermark).
- branch `media` — rendered videos waiting to be published. Each one is removed after it is posted.

Content rule: only TCG Pocket cards, original designs (Illus. Arturo Vega) or extended arts.
Never cards that exist as real printed cards.
